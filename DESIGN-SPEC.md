# Ai - dvokat: материалы для дизайна

Статус на 02.11.2026: название и юридический знак уже включены по указанию владельца. Компоновка, палитра и шрифты приложения сохраняются до утверждения макетов. B1/B2 подготовлены и выключены; B5 скрывает лишние элементы только у пользователя. Эта спецификация описывает входные материалы для будущей команды на редизайн, а не разрешает менять стенд.

## 1. Название и знак

Точное написание: **Ai - dvokat**. Направление: юридический консультант. Текущий знак — весы внутри диалога; исходный PNG с прозрачностью: `src/lib/custom/brand/logo.png`, 1254 × 1254. Запрос генерации сохранён рядом в `PROMPT.txt`.

Нужны мастер SVG с настоящими векторными контурами (без вложенного bitmap, внешних ресурсов и скриптов) и прозрачный PNG не менее 1254 × 1254; светлый и тёмный варианты, монохромный вариант, охранное поле и минимальный размер. Текущий `favicon.svg` содержит растровый знак и не заменяет мастер-вектор. Надпись должна оставаться читаемой отдельно от знака на маленьких экранах.

Экспорты в `static/static/` (точные размеры текущих файлов):

| Файл | Размер, px | Требование |
| --- | --- | --- |
| `favicon-16x16.png` | 16 × 16 | Упрощённый читаемый знак |
| `favicon-32x32.png` | 32 × 32 | Упрощённый читаемый знак |
| `favicon-96x96.png` | 96 × 96 | Прозрачный PNG |
| `favicon.png` | 512 × 512 | Прозрачный PNG |
| `favicon.ico` | 16 × 16 и 32 × 32 внутри ICO | Оба размера |
| `favicon.svg` | viewBox 0 0 500 500 | Вектор, масштабируемый |
| `apple-touch-icon.png` | 180 × 180 | Фон и поля согласовать |
| `web-app-manifest-192x192.png` | 192 × 192 | PWA |
| `web-app-manifest-512x512.png` | 512 × 512 | PWA |
| `logo.png` | 500 × 500 | Основной экспорт |
| `splash.png` | 500 × 500 | Светлый фон |
| `splash-dark.png` | 500 × 500 | Тёмный фон |

Дополнительно используются `static/favicon.png` (512 × 512) и `static/custom/logo.png` (1254 × 1254); не оставлять в них старую версию знака. Экспортёр: `src/lib/custom/brand/export-assets.mjs`. Согласовать отдельные значения `theme-color` и `background_color` для светлой/тёмной темы и безопасное поле PWA-иконки. Никакие цвета здесь не назначены за дизайнера.

## 2. Палитра и типографика

Сейчас в `src/custom.css` только `--custom-ink: currentColor` и `--custom-font: var(--font-sans, sans-serif)`. Они не заменяют палитру upstream. Дизайнеру нужно заполнить таблицу; новые переменные ниже — предлагаемый контракт будущего редизайна, пока в CSS они не объявлены и не применены.

| Токен | Назначение | Светлая тема | Тёмная тема |
| --- | --- | --- | --- |
| `--custom-background` | Фон страницы | согласовать | согласовать |
| `--custom-surface` | Карточки, панели и модальные окна | согласовать | согласовать |
| `--custom-text` | Основной текст | согласовать | согласовать |
| `--custom-text-muted` | Подписи, вспомогательный текст | согласовать | согласовать |
| `--custom-accent` | Основное действие, ссылки | согласовать | согласовать |
| `--custom-on-accent` | Текст на акцентном фоне | согласовать | согласовать |
| `--custom-success` | Подтверждённый успех | согласовать | согласовать |
| `--custom-warning` | Ограничения и неполные данные | согласовать | согласовать |
| `--custom-error` | Ошибка | согласовать | согласовать |
| `--custom-border` | Границы, разделители | согласовать | согласовать |
| `--custom-ink` | Совместимый алиас основного текста | согласовать | согласовать |
| `--custom-font` | Основное семейство и fallback | согласовать | согласовать |

Для каждого цвета указать точное значение и применение; для интерактивных элементов показать hover, focus, active и disabled. Смысл статусов должен читаться по тексту/значку, а не только по цвету. Отдельно проверить длинные юридические тексты, ссылки, таблицы и выделенную цитату в обеих темах.

По шрифту нужны семейство, начертания/веса, размер и межстрочный интервал для текста, заголовков, подписей и кнопок; проверка кириллицы, латиницы, чисел и юридических символов. Передать локальные WOFF2 (либо согласованный variable font), файл лицензии и уведомления об авторстве; без внешних CDN. Сейчас upstream содержит Inter и Vazirmatn в `static/assets/fonts/`; замена пока не согласована. Вместе с шрифтами описать fallback и загрузку без скачка компоновки.

## 3. Макеты и текущие снимки

Минимум: desktop 1280 × 900 и mobile 390 × 844, светлая и тёмная темы. Макеты должны учитывать длинные названия, переполнение и клавиатурный фокус. Не добавлять экраны или возможности сверх брифа.

Снимки — локальные материалы владельца в игнорируемом `private/handover/`; в публичный fork и Docker они не входят. Документы в карточке/источниках закрыты масками. Для передачи дизайнеру владелец выбирает допустимые снимки отдельно.

| Экран | Что показать в макете | Текущее состояние |
| --- | --- | --- |
| Вход | Знак, название, поля, ошибки, ожидание | [login.png](private/handover/login.png) |
| Старт | Шесть действий, черновик, выбор модели, вложения; недоступная модель | [start.png](private/handover/start.png) |
| Чат с результатом | Шесть вкладок: Итог, Находки, Правки, Источники, Файлы, Расход и время | [saved-result.png](private/handover/saved-result.png) |
| Источник | Боковая панель: фрагмент, цитата, редакция, дата, абзацы, сверка, ссылка К+ | [sources.png](private/handover/sources.png) — сейчас вкладка источников B2; полной панели B3 ещё нет |
| Боковая панель | Чаты и папки, длинные названия, свёрнутое состояние; user/admin | [sidebar.png](private/handover/sidebar.png) |
| О продукте | Описание Ai - dvokat, версия, лицензии | [about.png](private/handover/about.png) |

Для результата нужны состояния: загрузка, выполняется, готово, частично, ошибка, доступ запрещён, неизвестные поля, старый сохранённый ответ без job_id. Для источника — нет фрагмента/редакции, сверка не выполнена и API ещё не подключён. Не изображать неполные данные как успешную проверку. Макет панели дела B4 сейчас не запрашивается сверх перечня handover; её техническая заглушка не определяет будущий дизайн.

## 4. Комплект передачи

Нужны исходник макетов с компонентами/состояниями, экспорт PNG или PDF для просмотра, SVG/PNG/ICO из таблицы, заполненные токены обеих тем, локальные файлы шрифта и лицензия. Указать версии файлов и спорные решения, требующие ответа владельца. После утверждения владелец отдельно даёт команду на редизайн; до неё стенд не перекрашивается.
